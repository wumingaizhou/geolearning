## 今年总结

我感觉测绘程序设计这个比赛，对我来说是高投入，中风险，中回报。

高投入是因为准备时间太长了，6 个赛题一个一个准备，每次都要找资料，然后写枯燥的代码，每次打开都是流程性的写 openfiledialog 啥啥的，挺枯燥的，然后又不清楚自己写的代码对不对，结果对不对，找的资料又对不对。

中风险是因为，大家要知道，6 个赛题是 6 选一而不是 6 抽一。出题人其实在给出 6 道题目的时候，心里就已经知道国赛该出哪道题了，抽题是不可能的。如果你刚刚好对这个题目不了解，就非常难了，程序设计一旦某个环节出了问题，后面的答案就几乎全都不对。

中回报就不多说，当然只是对于我来说，因为这个比赛并不是我们专业的保研竞赛，我打这个比赛更多的只是给将来多一点保障。

此外，今年赛题里，没给你任何正确答案去检验你的成果正确性，为什么呢？其实很简单，因为去年和前年的赛题，就是因为给的正确答案是错的，导致大部分选手赛后都在骂，所以最简单的方法就是不给正确答案。所以，往后的比赛，估计都不会给检验答案了。

明年再见吧。
