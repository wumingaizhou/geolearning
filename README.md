## 经验之谈

1. 不要在比赛开始之前，也就是 10 点整之前创建代码项目或者doc报告文档，因为提交成功的时候，他是会判断你文件生成的时间的，如果是在 10 点之前的文件，那么就会提交不上去。不要为了图快，等 10 点后再开始创建项目也不迟。
2. 保持冷静，不求快，只求准确。程序正确性是一条线，如果哪一步错了，那么后面的结果也都会错。时间分第一名和最后一名也就相差 8 分，远远不如程序正确性的分值。
3. 报告文档也要练，今年报告文档的分值提上去了，需要特别注意一下。
4. 需要注意的是，近两次国赛，文档里给的检验答案都出现错误的情况。可以动点小手段。比如就拿图幅计算来说，你把你桌面上的某个软件快捷键，或者文件夹名称，或者多个，改成某个点的图幅编号，然后比赛的时候就能够放心的检验自己的正确性。当然，不是所有题目都适用。
