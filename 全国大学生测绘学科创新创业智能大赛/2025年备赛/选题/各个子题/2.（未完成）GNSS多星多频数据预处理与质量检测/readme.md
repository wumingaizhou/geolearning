## 2. 算法原理

根据的是我前面说的那个博主的算法写的，他每个方面只用一个方法。

### 1. 周跳检测与修复算法

#### 1.1 Melbourne-Wubbena (MW) 组合检测法

**核心原理：**
MW组合是一个无几何距离、无电离层影响的载波相位与伪距组合观测量，对周跳敏感。

**计算公式：**

```
MW = (L1 - L2) - (P1 - P2)/(λ1 - λ2)
```

其中：

- L1, L2：L1和L2频率的载波相位观测值
- P1, P2：L1和L2频率的伪距观测值  
- λ1, λ2：L1和L2频率对应的波长（0.19029367m 和 0.24421021m，已知值）

**检测逻辑：**

1. 按卫星ID分组处理所有观测数据
2. 对每颗卫星的观测数据按时间排序
3. 逐历元计算MW组合值
4. 计算相邻历元MW值的差值
5. 当差值超过阈值（0.3周）时，判定发生周跳

#### 1.2 周跳修复方法

**修复策略：** 线性内插法

当检测到周跳时：

1. 找到发生周跳的观测数据点

2. 确保该点不是序列的首末点

3. 取前后相邻观测值的平均值作为修复值：

   ```
   修复值 = (前一历元值 + 后一历元值) / 2
   ```

---

### 2. 多路径误差处理算法

#### 2.1 多路径效应估算

**物理原理：**
多路径效应是指GNSS信号经过反射后到达接收机，造成伪距观测值偏大的现象。

**计算公式：**

```
MP1 = P1 - L1 × λ1
```

其中：

- MP1：L1频率的多路径误差
- P1：L1频率伪距观测值
- L1：L1频率载波相位观测值
- λ1：L1频率波长

**处理流程：**

1. 按卫星分组计算每个观测值的多路径误差
2. 对同一颗卫星的所有观测值求平均，得到该卫星的多路径估计值
3. 用于后续的误差修正

#### 2.2 多路径误差修正

**修正方法：**

- P1修正：直接减去估算的多路径误差值
- P2修正：假设L2的多路径误差是L1的80%，按比例修正

```
P1_corrected = P1 - MP_estimate
P2_corrected = P2 - MP_estimate × 0.8
```

---

### 3. 卡尔曼滤波伪距平滑算法

#### 3.1 算法原理

卡尔曼滤波器用于融合伪距和载波相位观测值，得到更精确的距离估计。

**状态模型：**

- 状态变量：卫星到接收机的真实距离
- 测量值：伪距观测值（含噪声）
- 预测值：载波相位×波长（高精度但有模糊度）

#### 3.2 滤波器实现

**初始化：**

```
状态初值 = 第一个伪距观测值
协方差初值 = 1.0
过程噪声 = 0.01（默认）
测量噪声 = 1.0（默认）
```

**预测步骤：**

```
x_pred = x_previous           // 状态预测
P_pred = P_previous + Q       // 协方差预测
```

**更新步骤：**

```
K = P_pred / (P_pred + R)     // 卡尔曼增益计算
x_new = x_pred + K × (z - h)  // 状态更新
P_new = (1 - K) × P_pred      // 协方差更新
```

其中：

- z：伪距测量值
- h：相位预测值（L1相位×波长）
- K：卡尔曼增益（权重因子）

#### 3.3 平滑结果输出

- **SmoothedP1**：平滑后的P1伪距值
- **SmoothedP2**：按原始P1/P2比例调整的P2值

---

### 4. 数据处理流程

#### 整体处理顺序：

```
原始GNSS观测数据
    ↓
1. 周跳检测（MW组合法）
    ↓
2. 周跳修复（线性内插）
    ↓
3. 多路径估算（相位-伪距差值法）
    ↓
4. 多路径修正（误差扣除）
    ↓
5. 伪距平滑（卡尔曼滤波）
    ↓
高质量GNSS观测数据
```
